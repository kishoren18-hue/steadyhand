# Changelog

## 0.3.0 (2026-11-11)

- **Fixed: a confident "rest" prediction no longer counts as a misfire.** It
  holds the device still, so it is a missed movement, not an unintended one.
  Every result was rerun; the active rate is replaced by *correct movements*
  (share of intended motions the controller performed). `harmful(pred, y, rest)`,
  `ConformalCutoff(rest=...)` and `voted_misfire_curve(..., rest=...)` are new.
- New: label-efficient adaptive cutoff (`AdaptiveCutoff(feedback_rate=p)`,
  `simulate(..., rate=p)`): importance-weighted updates on every decision, with
  the bound in expectation over all decisions when only a random share p get
  feedback. The old rule moved p times slower and failed after electrode shift.
- New baselines: prequential retraining (every 5 s, from the same feedback),
  retraining + conformal, retraining + adaptive, per-class ROC cutoffs (Menon
  et al., EMBC 2015).
- Main finding changed: a cutoff alone cannot restore control after a large
  change (19% correct movements after electrode shift); retraining plus the
  adaptive cutoff kept all 91 users at or below every target on all four datasets.
- `contrib/libemg/`: a dependency-free module proposed for LibEMG, tested
  against LibEMG's own rejection block.
- Paper rewritten (`paper/main.pdf`); every number regenerated by
  `experiments/paper_assets.py`. 254 tests.

## 0.2.0 (2026-11-05)

- `steadyhand` is now an installable package with a small public API:
  `ConformalCutoff` and `AdaptiveCutoff`.
- New: adaptive cutoff with a per-user misfire guarantee on any data sequence,
  tested under electrode shift (21 people) and limb-position change (12 people).
- New: motion-level controller ("act on what's certain") on 3DC.
- New datasets: CIIL electrode shift, Fougner limb position.
- 190 tests, including checks against LibEMG's own rejection and voting code
  and worst-case sequences for the adaptive guarantee; continuous testing on
  Python 3.10 to 3.12.

## 0.1.0 (2026-11-04)

- Conformal cutoff across people, personal check, majority-vote calibration.
- UCI (36 people) and 3DC (22 people), shared and user-specific models.
- Interactive demo.
