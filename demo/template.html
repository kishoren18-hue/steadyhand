What's going on

A classifier turns each 250 ms slice of muscle signal into a gesture and a confidence score. LibEMG, an open-source prosthetics library, lets the hand move only when that score is above a fixed cutoff, 0.90 by default. On people the model has never seen, those scores are overconfident, so a fixed cutoff can't tell you how often the hand will move the wrong way.

SteadyHand keeps LibEMG's rule and picks the cutoff differently. You set a target misfire rate. Conformal risk control computes a cutoff from other unseen people that keeps the average new user under that target. A short check on the new person's first recording can only raise the cutoff, never lower it, which protects the people the model fits worst.

Limits: offline recordings from 36 able-bodied people, one dataset, no amputees and no physical hand. The guarantee holds on average across people, not for every individual. Data: UCI "EMG Data for Gestures" (Krilova et al., 2018). Library: LibEMG (Eddy et al., 2023). Code and full results: github.com/kishoren18-hue/steadyhand.
